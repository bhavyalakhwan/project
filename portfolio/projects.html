Machine Learning & NLP

Sentiment Analyser

GitHub ↗ Live Demo 🌸

An NLP model trained on a curated corpus of 50,000 tweets to classify sentiment polarity as positive, negative, or neutral. I fine-tuned a BERT-base architecture using Hugging Face Transformers, achieving 87% test accuracy.

The workflow covers comprehensive text normalization, subword tokenization, class rebalancing with SMOTE, and an interactive Flask API endpoint with visual metric reporting.

Computer Vision

Handwriting OCR

GitHub ↗ Live Demo 🌸

A deep convolutional neural network that segments and transcribes scanned handwritten notes into cleanly structured digital text. Trained on the IAM Handwriting Database, it reaches 92% character-level recognition fidelity.

Addressed complex preprocessing challenges using adaptive Gaussian thresholding, custom spatial image augmentations, and an n-gram language model post-processor for error correction.

PythonTensorFlowOpenCVNumPyMatplotlib

Study Planner App

GitHub ↗ Live Demo 🌸

A web productivity tool tailored for college students to strategically pace study intervals. Includes an intelligent scheduler calculating study sessions based on syllabus size, exam countdowns, and self-reported difficulty coefficients.

Engineered with a lightweight Python Flask service, responsive glassmorphism UI in vanilla JavaScript and CSS, with SQLite transactional persistence.
